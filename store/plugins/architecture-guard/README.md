# Architecture Guard

Check directed static module imports against explicit forbidden imports and layer rules; return evidenced dependency-cycle witnesses. Supplied source only, never execute a project.

## Input and scope

The analyze tool accepts explicit files (path, source, kind=source/test), packages (name, root, entry), and rules (forbidden prefix pairs, named prefix layers, allowed directed layer pairs, defaultPolicy=allow/deny). The complete closed nested schema is schema.json. No file discovery, project/config execution, filesystem, network, model or delegated tools.

Limits: 24 files; 8192 UTF-8 bytes per file; 32768 total source bytes; 48000 serialized input bytes; 6000 AST nodes; depth 100; 256 call edges/issues and bounded graph inventories; 1024 pending references per file; 1024-character evidence pointers; 20000 binding/export resolution steps with depth 100; 12 packages/changes/layers, 24 forbidden pairs and 48 allowed pairs. Output refuses above 42000 content or 58000 wire bytes; no clipping. Paths are literal, case-sensitive, forward-slash relative ASCII segments, at most 96 characters, with no traversal/device/ADS names. Package roots and layer prefixes must not overlap. Source identities represent real trees: a file cannot also be an ancestor directory or package root. Dense arrays admit only own index/length data descriptors; hidden keys, symbols, accessors and toJSON are refused before serialization (in-process API defense, not a remote-code-execution claim).

Babel parser/traverse 8.1.0, MIT; Node ^22.18.0 or >=24.11.0, tested Node24.20.0. Runtime dependencies are locked and bundled with full licenses in THIRD_PARTY_LICENSES.md. JS/JSX/TS/TSX ES modules only. Resolver supports explicit package entry identities, relative extension/index candidates and .js/.jsx to .ts/.tsx candidates; multiple matches remain unresolved. No tsconfig aliases, package exports/subpaths, node_modules, CJS, runtime loaders or arbitrary config. Type-only static dependencies are included in architecture policy and cycle analysis.

Supported call evidence: lexical function/arrow bindings, immutable local aliases, named/default/namespace static-property imports and named/star reexports. Export resolution distinguishes absent, resolved, ambiguous and unresolved states; nested ambiguity is never discarded, identical-origin diamonds resolve, and explicit named exports override stars. Identifier default exports and erased type queries do not count as runtime escapes. Arrow/function values in arrays, objects, arguments or returns are escaping even when their bodies have valid static call evidence; immutable bindings and direct invocation remain supported. Callers are actual resolved direct-call sites, with transitive reverse reachability; imports alone are not callers. Supplied test roles are reachability candidates, not executed tests or coverage. Unsupported dynamic/computed calls, constructors, classes/methods, JSX runtime edges and escaping callbacks are incomplete; TS namespaces/import-equals/export-assignment are refused. Complete means only the declared supplied static subset, never all runtime behavior. Evidence offsets/columns are JavaScript UTF-16 code units; lines are one-based and pointers refer to Babel File AST.

Architecture direction is importer to imported, including reexports/type dependencies. Forbidden rules always deny; allowed pairs grant edges, defaultPolicy governs unlisted/intra-layer/unassigned edges. Cycles are violations: one closed evidenced witness per strongly connected component, not every possible cycle. Incomplete graphs return policySatisfied:null, never a safe verdict.

Native results use invocation-scoped cards. Six locales cover ready descriptions, cards, complete/incomplete summaries and generic non-echo errors; identifiers/evidence remain literal. This local qualification is not chat approval, OS sandbox certification, complete target-version application execution, signed publication or automatic selected-project access.
