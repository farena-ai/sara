# Built-in skills

These are the starter skills that come with Sara (Phase 96). Each folder is a skill in the open
[Agent Skills](https://agentskills.io/specification) format: a `SKILL.md` with a `name` and a
`description`, and sometimes a `references/` folder. They are read only inside Sara; every companion
has them switched on until you switch one off in Settings → Abilities → Skills. To change one, use
"Copy to my skills" there and edit the copy (yours wins over the built-in one).
