Setup and recovery help
Only the host operator can configure allowed models, provider keys and spending limits using the offline business configuration command. This screen never accepts provider keys.
For lost sign-in, ask the host operator for a private re-enrollment code. A disabled account also needs fresh passkey enrollment, organization reapproval and separate workspace reapproval.
Archive restore closes access and pauses spending until the operator reconciles fresh passkeys, grants and uncertain usage. Refreshing or retrying does not clear a hold.
