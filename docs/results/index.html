How it is run

  • Tasks: bench/tasks and bench/projects, original to this repository. Reference solutions exist only to prove each task is solvable and that its hidden tests fail on the starting code (node scripts/bench-compare.ts --mode verify).
  • Other harnesses are the CLIs their users installed, with their own keys and settings; this repository holds only the command line used to call them, never their code. A harness's model is shown when its owner said which one it uses.
  • Each task runs once (pass@1) in a throwaway folder outside the repository, with the same time limit for everyone; whatever is left when the time is up is what gets graded.
  • Sara's rows use a local model through her normal agent loop; the "no harness" row is the same model answering once with every file, to show what the loop adds.
  • Never a better run hiding a worse one: the score is the newest full run, "every run" lists all runs of that day, and all of them are kept in docs/results/*.json (what changed between runs: docs/RESULTS.md).

Run it yourself

node scripts/bench-compare.ts --mode verify     # no model: checks tasks and the grading pipeline
node scripts/bench-compare.ts                   # every harness found on this computer, then this page
node scripts/bench-compare.ts --harness aider   # one harness (add your own in evals/harnesses.json)
node scripts/bench-compare.ts --page            # rebuild this page from docs/results (offline)
